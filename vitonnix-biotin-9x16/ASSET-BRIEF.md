# Vitonnix Biotin reel: shot prompts and asset checklist

Generate these, send them back named by ID, and I build the smooth final.

Reference image to attach to every product prompt: `source/ref-biotin-bottle.png`.

## Before you start

- **Always attach the reference bottle image.** Use an edit or reference mode, for example Nano Banana Pro, GPT Image 2, Seedream 4 edit, Flux Kontext or Higgsfield Product Photoshoot. Text-only prompts redraw the label and garble "Vitonnix".
- **Zoom in on the label before you keep a take.** Reject any image where the logo, "Biotin" or the small print changed. Make 3 or 4 takes of each shot and keep the cleanest.
- **No text inside the images.** I set all type in the edit, so the images stay clean and the words stay sharp.
- **Size.** Stills at 2160x3840 for 9:16 (at least 1080x1920), PNG or best-quality JPG, no watermark. Videos: 9:16, 5 seconds, MP4, no audio, no watermark.
- **Videos start from an approved still.** Use image-to-video (Kling, Veo 3, Seedance, Runway or Higgsfield) with the listed start frame. Smooth, slow camera moves cut together best.
- **Name files by ID.** For example P1-hero-34.png and V1-orbit.mp4, then upload them in this chat.
