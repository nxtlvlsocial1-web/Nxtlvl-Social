# Storylines — Nxtlvl Social brand film (32 s, 16:9, website hero)

Recommendation: **A · One café, four screens** — it is the only one a stranger follows as a story
(one business, one piece of content travelling through the four services), and it shows the
work rather than naming it. The user asked for the file with no stops, so A is built; B and C
are kept here so a later turn can switch.

## A · One café, four screens (built)

- **Device:** one object across apps. **Form:** SaaS motion design: floating UI surfaces, a brand
  cursor, cuts on the beat.
- The viewer sees The Corner Café's chai photo become a designed post, a captioned reel, the hero
  of a website, and a month of automated posting, each on its own floating surface, then the
  Shooting Star strikes and the studio's name lands. They feel "that is my shop, and it would
  only take one call".
- **First two seconds:** on the ink ground, giant type "Your **feed**" with the accent word
  rolling on the beat: feed → reels → website → replies.
- **Beats:** hook (type roll) → design (post assembles under a cursor) → reels (phone, captions
  slam on the beat) → website (browser window builds, button clicked) → automation (calendar
  fills, toasts stack, counter) → end card (star strike, lockup, Book a free call).
- **Look:** ink `#05030C` with violet light, Archivo 800 display, Instrument Serif for the one
  emphasised phrase, UI surfaces as tinted glass cards (2 px border, 24 px radius).
- **Sound:** original 120 BPM electronic bed composed for the cut (intro → drop at 4 s → lift →
  impact at 22 s → bell at 27.5 s); pops on chips, key ticks on typing, click on each cursor
  press, one riser into the impact, one whoosh per cut.

## B · The feed fills itself (not built)

- **Device:** the result first. **Form:** one phone, one continuous push.
- An empty Instagram profile fills tile by tile on the beat, each tile a different Nxtlvl
  deliverable; the camera pulls back to a wall of feeds for cafés, salons and gyms.
- First two seconds: "0 posts" on a phone, the first tile slams in on beat one.
- This is the shape of the earlier promo (nxtlvl-promo-16x9); not rebuilt here.

## C · Type carries the argument (not built)

- **Device:** type carries the argument. **Form:** full-frame kinetic type and colour fields
  cutting on every beat, no UI at all.
- Twelve short claims ("Posts. Reels. Websites. Replies. Finished by a designer.") slam in with a
  different entrance each, backgrounds flipping ink ↔ violet, resolving on the Shooting Star.
- First two seconds: "YOUR" fills the frame, "ENTIRE" slams over it.
- Strongest as a 10 s sting; at 32 s it has no story, so it was not picked.
