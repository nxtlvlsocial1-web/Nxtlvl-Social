# Creedom "@write-script", made to measure: ElevenLabs voiceover (female, Eleven v3 audio tags)

Same lines as the v3 reel, with mood tags for Eleven v3. About 35 s.

## Paste into ElevenLabs (model: Eleven v3)

```
[frustrated sigh] I tried on forty AI scripts last week... [deadpan] Not one of them fit.

[sarcastic] They're all off the rack. Same hook. Same "let's dive in!" [exasperated] For every creator on earth.

[softly] Because none of them... have ever heard you talk.

[curious] So I opened Cree-dum, and typed... [playful] at write script.

[intrigued] First, it takes your measurements. [upbeat] How you open. Where you pause. [laughs] The words you can't stop saying.

[excited] Then it cuts a script to fit you. [building energy] Hook... story... call to action... [proud] stitched in your voice.

[delighted laugh] It sounds like me... [warmly] on a really good day.

[confident] Comment SCRIPT... [playful] and I'll send you the link.
```

## Settings

- Model: Eleven v3 (the audio tags only work on v3).
- Stability: Creative for the most emotion, or Natural if a take overacts.
- Voice: a warm, young female narrator. The Creedom reel-analyser script used "Nota 3" (rTMkoe3NzNrEOgFeBwY2).
- Make 3 or 4 takes and keep the best one. If the take runs over 35 s, speed it up 1.05x to 1.1x in the edit.
- "Cree-dum" is spelled that way so the voice says Creedom right. If it already says "Creedom" correctly, you can type
  it normally.
