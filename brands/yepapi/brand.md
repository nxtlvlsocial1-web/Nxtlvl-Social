# YepAPI brand kit (client)

Source: the client's logo PNG and yepapi.com (captured 2026-11-10 with `npx hyperframes capture`).
Colours, fonts and logo files below are the brand's own; nothing here is redrawn.

## Files

| File | Use |
|---|---|
| `logo.svg` | Lockup (thumb mark + black "yepapi" wordmark) on light backgrounds |
| `logo-light.svg` | Lockup with white wordmark, for dark backgrounds |
| `mark.svg` | Thumb mark alone (lemon rounded square), when the name is already next to it |
| `fonts/SpaceGrotesk-latin-var.woff2` | Space Grotesk, variable 300–700, Latin subset (OFL) |
| `fonts/GeistMono-latin-var.woff2` | Geist Mono, variable 100–900, Latin subset (OFL) |

Inter (the site's body face) is bundled with HyperFrames; no file needed.

## Colour

| Name | Hex | Use |
|---|---|---|
| Lemon | `#FFF56C` | Signature ground: site header, CTA band, logo tile |
| Ink | `#0A0A0A` | Site background, type on lemon, wordmark |
| Thumb blue | `#2D33BA` | The thumb illustration; strong secondary ground |
| Sleeve pink | `#FE4A97` | The sleeve; one accent at a time |
| Cuff green | `#00C38A` | The cuff; success / "200 OK" moments |
| White | `#FFFFFF` | Text on ink and blue |

The site uses ink as its page colour, with lemon for the header, buttons and the closing CTA band.

## Type

- Headlines: Space Grotesk 700, tight tracking (−2% to −4%).
- Body / UI: Inter 400–700.
- Code, endpoints, prices: Geist Mono.

## Facts we can say (from yepapi.com)

- One API key for SEO data, scraping, social data and AI models.
- From $0.01 per call. No subscriptions, no tiers, no minimums.
- $5 free credit, no card required.
- SEO endpoints include `/v1/seo/domain/keywords`, `/v1/seo/competitors/domain`, `/v1/seo/backlinks/referring-domains`.
- Works with AI agents: an MCP server, and Claude Code / Cursor / Codex read its llms.txt.

## Don't

- Don't recolour or redraw the thumb mark; on a lemon ground give the tile an ink outline or offset shadow so it separates.
- Don't invent dashboards or numbers and present them as YepAPI's. Example data must be labelled.
