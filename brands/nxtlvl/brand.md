# Nxtlvl Social brand kit

**Logo: the Smooth N.** One continuous rounded stroke forms an N that ends higher than it starts (the next level), with a
small spark off the end (the idea). Wordmark: "nxtlvl" in Archivo Bold (width 108%, tracking −3%), "social" in Instrument Sans Regular.

## Files

| File | Use |
|---|---|
| `logo.svg` / `png/logo@4x.png` | Main logo on white or light backgrounds |
| `logo-white.svg` / `png/logo-white@4x.png` | On dark backgrounds (website, video end cards) |
| `logo-stacked.svg`, `logo-white-stacked.svg` | Square spaces: social covers, stickers |
| `logo-mono-black.svg`, `logo-mono-white.svg` (+ stacked) | One colour: print, stamps, embroidery, watermarks |
| `mark.svg`, `mark-white.svg`, `mark-black.svg` | The N alone, when the name is already next to it |
| `icon.svg` / `png/icon-1024.png` … `icon-32.png` | App icon, favicon set, WhatsApp Business profile |
| `profile.svg` / `png/profile-1024.png` | Instagram, LinkedIn, YouTube profile picture (platforms crop the circle) |
| `favicon.svg` | Browser tab icon |

All SVGs are pure vector (text outlined), so they open in Canva, Figma, Illustrator and any browser without fonts.

## Colour

| Name | Hex | Use |
|---|---|---|
| Ink | `#05030C` | Dark backgrounds |
| Ink text | `#0B0816` | Wordmark on light |
| Violet | `#7D18FC` | Primary accent, buttons |
| Lift | `#A95CFF` | Spark, gradient end |
| Deep | `#5E0FC4` | Gradient start |
| Pale | `#D8BBFF` | Spark on dark, highlights |
| Mist | `#F5F2FF` | Light backgrounds, text on dark |

Mark gradient: Deep → Lift, bottom-left to top-right.

## Rules

- Clear space: half the mark's height on every side. Minimum size: mark 24 px, full logo 120 px wide.
- Use the white version on dark or photo backgrounds; never recolour the mark outside the palette.
- Don't stretch, rotate, add shadows or outlines, or put the gradient logo on a violet background (use the white version there).
- Type: Archivo (headlines), Instrument Sans (text), Instrument Serif (accents). Fonts are in `website/fonts/`.
