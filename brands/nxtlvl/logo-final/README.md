# Nxtlvl Social logo (final)

The rocket: a white four-point star with three trailing streaks, on the violet gradient tile, beside the "nxtlvl social" wordmark.
The squiggly "N" files elsewhere in `brands/nxtlvl/` are not this logo.

| File | Use |
| --- | --- |
| `nxtlvl-social-logo-for-dark-bg.svg / .png` | Full logo on dark backgrounds (wordmark white + pale lilac) |
| `nxtlvl-social-logo-for-light-bg.svg / .png` | Full logo on light backgrounds (wordmark ink + grey-violet) |
| `nxtlvl-social-icon-tile.svg / .png` | App icon, profile picture, favicon source (1024 px) |
| `nxtlvl-social-rocket-white.svg / .png` | The rocket alone, on dark backgrounds |
| `nxtlvl-social-rocket-ink.svg / .png` | The rocket alone, on light backgrounds |
| `nxtlvl-social-logo-overview.png` | All versions on dark and light, for reference |

SVGs scale to any size (print, signage, web). PNGs have transparent backgrounds.
Colours: tile #0A0620 with violet light #7E1AF6 / #5E06F2; star and main trail #FFFFFF; trails #A95CFF / #B98AFF; lilac #D8BBFF.
Keep clear space around the logo of at least half the tile's width; never stretch, recolour or redraw it.
