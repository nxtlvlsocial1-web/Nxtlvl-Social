# Nxtlvl Social: SaaS motion film kit

Everything needed to make the 30-second SaaS film, made in code with no generation API.

| Path | What |
| --- | --- |
| `Nxtlvl-Social-SaaS-Film-Kit.pdf` | The combined document: logo, every start frame with its prompt, the combined prompt, order, settings, costs |
| `logo/` | The real Nxtlvl Social logo (the rocket): lockup, app tile, white and ink marks (transparent PNG), Kling first/last frames 1:1 and 16:9 |
| `frames/` | Start frames 1920 x 1080: hello, dashboard, WhatsApp flow, lead capture, content and websites, growth, end card |
| `source/` | Rebuild: `python3 source/make_kit.py && node source/shoot.js`, then `python3 source/make_doc.py` and print `doc.html` to PDF with Playwright |

The squiggly "N" files in `brands/nxtlvl/png/` and `logo.svg` are not the Nxtlvl Social logo; use `logo/` here.
Mascot images come from `website/img/` (Nextyy, made with Nano Banana 3 Pro). Text, numbers and the logo are never generated by AI.
