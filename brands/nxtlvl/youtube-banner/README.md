# YouTube banner: AI creator channel (@ai.nxtlvl)

`youtube-banner-2560x1440.png` (or the lighter `.jpg`): the Shooting Star, "Discover the *world of AI.*",
AI tools · Automation · Innovation, and @ai.nxtlvl / New videos every week, on the logo's ground.

All text and the logo sit inside YouTube's all-device safe area (1235 x 338, centred), so nothing is cropped on
phones; desktop and TV show more of the starlit ground around it.
Upload: YouTube Studio → Customization → Profile → Banner image → Upload, then Done → Publish.
Rebuild with `python3 youtube-banner/source/build.py` from `brands/nxtlvl/`.
