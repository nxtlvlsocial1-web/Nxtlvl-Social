# Nextyy, the Nxtlvl Social mascot

The mascot used on the Nxtlvl Social website, at full size with transparent backgrounds (`png/`).
`nextyy-mascot-set.png` shows every version on one sheet.

| File | Where it is used on the site |
| --- | --- |
| `nextyy-wave.png` | Home hero |
| `nextyy-celebrate.png` | Closing "book a call" box |
| `nextyy-laptop.png` | "How it works" heading |
| `nextyy-phone.png` | Automation section |
| `nextyy-point.png` | Services heading |
| `nextyy-think.png` | Questions (FAQ) |
| `strategist.png` | Agents app, the strategist next to Nextyy |
| `agent-content.png`, `agent-reply.png`, `agent-ads.png`, `agent-edit.png`, `agent-seo.png`, `agent-report.png` | Agents app, one colour per agent |

Made for Nxtlvl Social with an AI image model (Nano Banana via YepAPI), cut out with rembg; agent colours are hue shifts of
the purple originals, matched to the site. Use them in posts, reels, decks and the site; keep the purple Nextyy as the main
character and the coloured ones for the agents.
