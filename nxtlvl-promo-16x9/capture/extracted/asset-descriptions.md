# Asset inventory — Nxtlvl Social

Source: the landing page file `website/index.html` in this repo (the brief's named source). The URL
capture tool refuses loopback addresses by design, so this folder was built by hand from the page
file itself: colours and fonts from its CSS tokens, copy from its markup, logo from its embedded PNG.

## assets/

- `assets/nxtlvl-wordmark.png` — the "nxtlvl" wordmark, white on transparent, 720×165. The brand
  logo; use on dark grounds. Pairs with the spark mark top-right of the wordmark.
- `assets/nxtlvl-spark.svg` — the four-point star "spark" in violet-lift #A95CFF. The brand's mark:
  appears after the wordmark, as the opening reveal on the site, and as the 3D star finale.
